# Portfolio — Alexy Durand

Portfolio d'Alexy Durand, étudiant en 3e année de BUT Informatique à l'IUT de Blagnac.

👉 [Voir le site](https://alexydurand.github.io/portfolio.alexydurand/)

## Au programme

- Mes compétences, orientées données (SQL, Power BI, Power Platform) et développement
- Mes projets, mon parcours et mon stage chez Orange
- Mes loisirs, mes voyages et un vol de nuit en 3D dans Hong Kong, animé au scroll

## Technologies

React, TypeScript, Tailwind CSS, Three.js, GSAP (ScrollTrigger) et Lenis, construit avec Vite.
La ville en 3D est modélisée entièrement en code. L'accueil est un parallax à plusieurs calques découpés dans une photo des Pyrénées.

## Lancer le projet

```bash
npm install
npm run dev
```

Build de production : `npm run build` (sortie dans `dist/`).

Le site est déployé automatiquement sur GitHub Pages à chaque push sur `main`
(`.github/workflows/deploy.yml`).
