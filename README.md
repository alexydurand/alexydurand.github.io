# Portfolio — Alexy Durand

Portfolio d'Alexy Durand, étudiant en 3e année de BUT Informatique à l'IUT de Blagnac.

👉 [Voir le site](https://alexydurand.github.io/)

## Technologies

React, TypeScript, Tailwind CSS, Three.js, GSAP (ScrollTrigger) et Lenis, construit avec Vite.
Le vol sur Hong Kong est une suite d'images tirée de deux vidéos Pexels, jouée au scroll. L'accueil est un parallax : un ciel beige, le nom, puis des collines sombres qui passent devant.
